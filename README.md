# SAC-based Beam Tracking in mmWave V2X Networks

This repository provides the Python implementation for Soft Actor-Critic (SAC) beam tracking in 60 GHz mmWave V2X communications.

## Setup & Dependencies
Install required packages using:
```bash
pip install -r requirements.txt

Execution
Train SAC Agent: python train.py

Evaluate Model: python evaluer_modele.py

Reproduce Paper Figures: python generates_all_figure.py
